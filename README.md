# SWING TRACE — Streamlit試験版

バット先端（赤）と両手の握りの中心（水色）をAIで推定し、両点を結ぶ通過面を黄色で重ねたMP4を出力します。

## GitHubへ配置
このフォルダーの中身をリポジトリ直下へアップロードしてください。動画、APIキー、Openai.docx、実際のsecrets.tomlはアップロードしません。

## Streamlit Community Cloud
GitHubリポジトリを選び、ブランチmain、エントリーポイントstreamlit_app.py、Python 3.12でデプロイします。Advanced settingsのSecretsへsecrets.example.tomlの内容をコピーし、APIキーと招待コードのプレースホルダーを実値に変更してください。招待コードは20文字以上のランダムな英数字を推奨します。ローカル版の招待コードは自動移行されません。

OPENAI_MODELがAPIに送るモデル名です。初期値はgpt-6-astraで、ログイン後のサイドバーでも確認できます。利用するAPIアカウントでモデルへのアクセスが必要です。

## 操作
招待コードでログインし、動画・開始時刻・解析時間・密度を指定して送信に同意します。最初は1秒、毎秒5枚で試してください。解析後に各コマを確認し、必要なら座標を数値で修正します。位置と面のつながりを確認した後、MP4を作成してダウンロードしてください。

## 試験版の範囲
- 同時処理は1件。100MB以下、解析区間は最大6秒、1回最大60枚です。
- 初期の予約枚数上限は全体60枚/日、招待コードごと20枚/日です。失敗した処理の予約も消費扱いです。日付はUTC基準です。
- 解析中はタブを開いてお待ちください。ページ再読み込みや再起動により結果を失う場合があります。
- 動画・座標・利用回数はサーバーの一時領域に保存します。24時間を超えた解析フォルダーは次の解析開始時に削除します。クラウド再起動によって早く消える場合があります。
- 利用回数も再起動で消える場合があるため、この上限は永続的な課金上限ではありません。小人数の招待制試験向けです。一般公開には永続ストレージ、永続的な利用制限、バックグラウンドジョブなどの追加が必要です。
- AI座標は誤る場合があります。出力前に確認してください。画像クリックによる修正ではなく、数値による修正です。
- 出力は選択区間のみ、30fps、無音です。2Dの推定表示で、速度測定や3D復元は含みません。
- ローカルで動くFastAPI版とは別アプリです。

## ローカル開発
requirements.txtをインストールし、.streamlit/secrets.tomlへ設定を置いて `streamlit run streamlit_app.py` を実行します。LinuxにはFFmpegとNoto CJKフォントが必要です。Community Cloudではpackages.txtで指定しています。
